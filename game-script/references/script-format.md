# 开发向剧本格式

剧本是给程序、美术、音频、本地化用的执行文档。判断标准很简单：
**程序不用问你就能实现，美术不用猜就知道要画什么。**

## 面向开发人员要拆出来的东西

原书只提"要把流程拆细"，实际项目里至少要覆盖这些：

| 类别 | 要写清的 |
|------|---------|
| 演出 | 消息显示速度、指定动画、指定影片/CG、淡入淡出、画面闪烁/闪黑闪白、镜头语言 |
| 文本 | 文字上限与分段、换行与翻页点、通用替换词（玩家名/性别代词） |
| 逻辑 | 分支跳转目标、flag 读写、前置条件 |
| 资源 | 角色 ID 编号、角色表情 ID、立绘位置、BG ID、BGM/SE ID、配音文件 ID |
| 本地化 | 哪些行需要翻译、哪些是变量、字数上限（翻译后会变长） |

## 本 skill 使用的轻量格式

纯文本，可被 `scripts/script_lint.py` 解析，也方便直接贴进 Excel/CSV 或 Ink/Yarn 转换。

```
# 场景 <scene_id>: <标题> / <时间>

* BG   <背景ID>
* BGM  <音乐ID>
* SE   <音效ID>
* CH   <角色> 进入 <位置>          # 或 退出
* CG   <CG_ID>
* FX   <效果说明>

<角色>（<表情或动作>）: <台词>
> <旁白>

? 选项组 (id: <选项组ID>)
  - 「<选项文本>」 -> <目标场景ID> [set: <flag 操作>] (需要: <前置条件>)

=> <目标场景ID>
```

### 各符号含义

| 符号 | 含义 | 备注 |
|------|------|------|
| `#` | 场景头 | **必须带地点和时间**（`/` 后为时间），对应指示的"何时/何地" |
| `*` | 指示行 | BG / BGM / SE / CH / CG / FX，可自行扩展 |
| `角色: 文本` | 台词 | 角色名建议直接用角色 ID，避免改名时全局替换 |
| `（）` | 表情或动作 | 有立绘的项目里，**每条台词都该有表情** |
| `>` | 旁白 | |
| `?` / `-` | 选项组 / 选项 | 每个选项至少要有 `->` 或 `[set:]` |
| `=>` | 无条件跳转 | 场景末尾用 |
| `//` | 注释 | 不进游戏 |

### 完整示例

```
# 场景 s02_manor_gate: 黑死馆前 / 深夜

* BG   bg_manor_gate_night
* BGM  bgm_tension_low
* CH   雷诺 进入 右

雷诺（举枪）: 举起手来！你从哪儿拿到的这张地图？
> 雨点砸在石阶上，溅起细碎的白。
* CH   老人 进入 左
老人（冷笑）: 不知道。
雷诺（逼近）: 快说！不然我可开枪了。
老人（回避）: 嘁……在黑死馆。

? 选项组 (id: s02_press)
  - 「继续逼问」   -> s03a_press   [set: threatened=1]
  - 「放下枪」     -> s03b_talk    [set: trust=trust+1]
  - 「提起座钟」   -> s03c_clock   (需要: knows_clock==1)
```

## 指示的最小信息集

每条指示至少要能回答 **何时 / 何地 / 何人**，视情况加第四个 **情况**：

| 指示 | 缩写 | 例 |
|------|------|-----|
| 指定背景 | BG (Background) | `* BG bg_manor_gate_night` |
| 指定角色 | CH (Character) | `* CH 苍老头 进入 左` |
| 指定时间 | —— | 写在场景头 `/ 深夜`，防止剧情 bug |
| 指定 BGM | BGM | `* BGM bgm_tension_low` |
| 指定音效 | SE (Sound Effect) | `* SE se_thunder` |
| 指定配音 | VO | `* VO vo_s02_0031`（与台词一一对应） |
| 指定情况 | FX | `* FX 画面闪白 0.2s` |
| 指定事件 | CG | `* CG cg_10021 终极大战特写` |

## 分镜（Continuity）

图画分镜和文字分镜都算，作用是让程序和美术不用猜。
代价是对写作者的美术与影视构图能力要求高——**做不到就退一步，用文字分镜**：

```
// 文字分镜
镜1 中景，雷诺背对镜头，雨幕，霓虹反射在地面
镜2 特写，老人的手在口袋里摸索
镜3 过肩，枪口进入画面右下角
```

## 交付前对齐的技术参数

写第一行台词之前就要问到（不然全部要重写）：

- 文本框最大行数 / 每行最大字数 / 单页总字数
- 是否支持字号变化、颜色、加粗
- 逐字显示速度、是否可跳过、是否有自动播放
- 角色 ID 与表情 ID 的命名规范
- flag 命名规范与作用域（章节内/全局/存档）
- 本地化预留：中译外通常膨胀 30%–60%，字数上限要按最长语言算

## 与主流叙事工具的对应

| 本格式 | Ink | Yarn Spinner | Excel/CSV 表 |
|--------|-----|--------------|--------------|
| `# 场景` | `=== knot ===` | node title | 场景 ID 列 |
| `角色: 台词` | `角色: 台词` | `角色: 台词` | 角色列 + 台词列 |
| `- 「文本」 -> 目标` | `* [文本] -> knot` | `-> 文本` + `<<jump>>` | 选项行 + 跳转列 |
| `[set: flag=1]` | `~ flag = 1` | `<<set $flag = 1>>` | flag 列 |
| `(需要: cond)` | `{cond: ...}` | `<<if $cond>>` | 条件列 |

先用本格式写作、评审、跑 lint，再一次性转成引擎格式，比直接在引擎里写返工少。
