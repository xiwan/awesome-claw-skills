# 主题与故事

## 创作流程的两个阶段

```
策划阶段：主题 → 游戏目的 → 世界/角色大纲 → 系统与剧情的分工
剧本阶段：故事梗概 → 结构（开端/过程/高潮/结局）→ 章节 → 场景 → 文本
```

两阶段之间有个常被跳过的动作：**在有策划框架的前提下，剧本必须服从框架**。
剧情和系统各写各的，最后一定对不上（玩家在系统上被迫接受了目标，情感上没接受，动力就断了）。

## 主题的两种写法

| 写法 | 例子 | 适合 |
|------|------|------|
| 一个词 | 生存 / 中二 / 黑道 / 复仇 | 玩法主导的项目，主题只需定调 |
| 一个长句 | "一对吵架夫妻合作闯关的奇妙旅行"（《双人成行》） | 叙事主导的项目，主题同时是卖点 |

长句主题的好处：它往往已经把游戏目的写在里面了（"合作闯关"），第一道门槛自动通过。

## 主题 → 故事的两道门槛

```
主题
 ├─ 问1：主题里包含游戏目的吗？（玩家具体要做什么）
 │    └─ 否 → 改主题，别硬写
 └─ 问2：主题足以创作故事吗？（能不能长出冲突和纠葛）
      └─ 否 → 主题太薄，加限定条件或换角度
      └─ 是 → 可以开始写故事
```

"故事"就是表达主题的具体内容。两道门槛都过了，才算有坚实的创作基础。

## 卡住时的三个出口

主题定了但故事憋不出来，按顺序试：

1. **话题库 / 创意库**——平时就记录零碎创意，用的时候翻。这是唯一需要长期投入的一条。
2. **借鉴原型**——图书、游戏、电影、新闻。看得越多能拆出的结构越多；
   注意抄袭与借鉴的界限，落点必须回到"游戏这个媒介能做什么"。
3. **从角色和世界反推**——先把角色细节钉死，再顺着角色的目的、关系网、
   世界设定长出故事。这条对"主题很虚"的项目最有效。

## 主题的两条表现路径（除此之外都是错的）

### 路径一：通过角色的选择与行为

给玩家一个体现主题两难的选择。例：主题"爱与正义的两难"

| 选项 | 表现的态度 |
|------|-----------|
| 舍弃爱情，选择正义 | 殉道者 |
| 舍弃正义，选择爱情 | 凡人 |
| 既要维护爱情又不放弃正义 | 理想主义者（通常代价最大） |

### 路径二：通过故事的发展与结局

上面的选择必须真的导向不同的后续与结局——这同时是引导玩家开二周目的手段。
如果三个选项汇流到同一个结局，主题表达和选项设计一起失效。

### 反例（最常见的处理）

```
角色A：「我终于明白了，友情才是最强大的力量！」
```

主题一旦被角色说出口，玩家立刻从"体验主题"退回"被告知主题"，违和感极强。
需要的是让玩家在做完某个选择后**自己**得出这句话。
