# 角色设定表

## 角色的定义

游戏剧本里的角色 = **有个性、目的、意志、感情，并依此生活/思考/心动的个体**。
角色是"形象与性质的总体"，所以设计角色就是设定形象（外部）与性质（内部）。

角色的意志、目的、感情、行动是推动故事的原动力。**最能看出编剧水平的两点**：
- 角色的目的和意志有多清楚
- 角色如何向着目标奋勇前进（而不是被剧情推着走）

## 四类设定表

复制这张表，一个角色一份。不必每格都填满，但四类都要有内容。

```markdown
## 角色：<名字>

### 基础
- 姓名：
- 年龄：
- 职业：
- 学识：
- 关系网：（与哪些角色是什么关系）

### 外部
- 相貌：
- 体格：
- 发型：
- 服装：
- 剪影特征：（缩成纯黑轮廓还能不能认出来）

### 内部
- 性格：
- 定位型性格：（父亲般/母亲般/公主般/总裁般…）
- 优点：
- 弱点：
- 爱好：
- 价值观：

### 特殊
- 剧本定位：（见 character-roles.md，可多个，注明切换时机）
- 口头禅：
- 特殊技能：
- 特殊装备：

### 剧本设定
- 在故事中的作用：
- 出场章节 / 退场方式：
- 与主题的关系：
```

## 各字段真正在做的事

| 字段 | 作用 | 反用手法 |
|------|------|---------|
| **名字** | 发音本身携带印象（"伏地魔""酷霸王"一听就不是好人） | 角色个性足够强时，名字随便起也压得住 |
| **年龄** | ① 暗示角色间关系（12 岁 + 35 岁更像母子而非姐弟）② 借年龄段的刻板印象 | 打破刻板印象就是反差感的来源 |
| **职业** | 借先入为主的印象省笔墨（医生=治疗/解 debuff，铁匠=打装备） | 反其道而行制造意外 |
| **发型** | 二次元角色的核心记忆点；发型变化 = 成长与心境变化的可视化 | —— |
| **体格** | 直观传达战斗定位（刺客瘦、坦克壮）；**剪影里最重要的区分维度**，玩家靠体格在群像里找人 | 配合标志道具（帽子、刀）进一步区分 |
| **服装** | 一次性传达性别、职业、性格、嗜好、思维方式 | —— |
| **性格** | 角色行为合理性的来源，也决定台词的说话方式与口吻 | —— |
| **定位型性格** | 让设定"莫名其妙就合理"（爷爷会通灵术 > 妈妈会通灵术）；性格类型的转变 = 立场变化的信号 | —— |
| **弱点** | 给反派深度、给主角亲近感，让角色变鲜活 | 无弱点角色最难代入 |
| **口吻** | 记忆点（听到某句口头禅就想到某角色） | —— |

## 主角的特殊规则：越有个性越难代入

游戏主角和电影主角相反：**个性越丰富，玩家越难把自己投射进去**。
"英雄性""中心性""特别身份"在游戏里不再是加分项。

两种主角设计路线：

| 类型 | 做法 | 典型 |
|------|------|------|
| **换位型主人公** | 主角贴近玩家：留白、无个性、外观/名字可定制、对话给选项 | 文字冒险、CRPG |
| **角色扮演型主人公** | 让玩家主动贴近主角：主角有完整人格与嘴替台词 | 剧情主导的日式作品 |

无论哪种，**主角的行动原则不能牵强**。玩家跟不上主角的动机就会出戏，
所以要么提前给足信息，要么把情境铺到"换谁都会这么做"。

## 角色行动的燃料：纠葛

纠葛 = 人与人的对立，或一个人内心几种互斥欲求之间的难以抉择。它是体现意志、目的、
感情最有效的手段，有两种表现形式：

- **外在**：战斗、对立、竞争、冲突
- **内在**：烦恼、纠结、思想斗争

没有纠葛的角色不会显得有意志，只会显得听话。

## 角色与故事的衔接：理由要落在个人层面

同一个故事目标（"消灭坏人，给世界带来和平"），理由的层级决定代入感：

| 理由 | 代入感 |
|------|-------|
| "这是总统的职责与义务" | 弱——公共身份把玩家推远 |
| "坏人杀了我的家人，我的右臂因此变成了植物" | 强——个人层面的动机 |

注意别过头：个人理由如果太私密、与世界完全无关，故事撑不到全局尺度。
