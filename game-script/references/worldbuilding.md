# 世界设定

## 从两个要素起手

世界设定从 **何时（时间）** 和 **何地（地点）** 出发，再向外长：
这里有什么样的人？科技水平如何？谁在统治？靠什么维生？

## 世界设定表

```markdown
## 世界：<名称>

### 时空
- 时代 / 年份：
- 主要地点：
- 地理与气候：
- 世界规模：（一座城 / 一个国家 / 一颗星球 / 多个平面）

### 人与社会
- 主要种族 / 群体：
- 政治体制与权力结构：
- 经济与生产方式：
- 宗教 / 信仰 / 禁忌：
- 语言与礼节：（影响台词，见 dialogue-craft.md）

### 技术与超自然
- 科技水平：
- 超自然体系：（魔法/异能/神明）
- **该体系的规则与代价**：← 最关键的一格
- 该体系不能做什么：← 第二关键

### 历史
- 关键历史事件：
- 当下的主要矛盾：
- 与主线的关系：

### 表现取舍
- 玩家必须知道的（要在游戏里明说）：
- 玩家可以推测的（藏在环境/道具/台词里）：
- 只给考究党的（设定集/收集品）：
```

**设定表不是每格都要填满，更不是每格都要在游戏里说出来。** 取舍标准：
主题需要吗？系统需要吗？故事需要吗？会不会让玩家信息过载？
设定可以做得很深，表现必须收着——深挖的部分留给考究党。

## 起手式："世界如果是这样的呢"

以一个假设为起点向下推，比直接写设定表快得多。

```
如果这个世界能使用魔法会怎样？
 ├─ 谁能用？   → 天生血统 / 后天学习 / 花钱购买
 ├─ 代价是什么？ → 寿命 / 记忆 / 社会地位
 ├─ 社会怎么变？ → 魔法取代工业？出现魔法阶级？
 ├─ 战争怎么打？ → 军队结构、反魔法手段
 └─ 日常怎么变？ → 照明、通信、医疗、交通
```

推到"日常怎么变"这一层，世界才开始像真的。只推到战争层面的世界通常很空。

## 世界必须有规则

规则 = 世界一切事件发生的**基础理论 / 基础规律**。缺规则的世界会同时丢掉说服力和真实感。

两类破绽和它们的修法：

| 破绽 | 例子 | 修法 |
|------|------|------|
| 违反现实常识且无解释 | 人从 100 米跳下没事 | 给设定（异能/护具/低重力） |
| 引入超自然但不给原理 | 世界突然有魔法，来源不明 | 给来源与代价 |
| 时代错乱 | 古代战争里出现坦克 | 给解释（虫洞穿越而来） |

关键不在于解释多科学，而在于**解释存在且前后一致**。

## 世界就活在系统里

游戏的世界不只在文本里，更在系统里。**策划写系统文档时，本质上就是在建构世界**：

- 伤害公式 → 这个世界的暴力如何生效
- 属性克制 → 元素之间的因果律
- 遇敌概率 → 这片区域有多危险
- 环境交互 / 物理 / 化学反应 → 物质如何运作
- 复活与存档 → 死亡在这个世界意味着什么

剧本和系统对不上的地方，玩家一定先信系统。所以世界规则要和系统数值同一份口径。

## 世界 ↔ 角色 ↔ 故事的三角

也可以从世界起手长出角色和故事：

```
剑与魔法的帝国 → 有王国 → 有国王 → 有公主 → 有护卫剑士 → 有战斗 → 有冲突 → 有故事
```

代价要清楚：**设定世界扩大了角色设定的安全范围，同时限制了角色设计的自由度**。
世界越具体，越不容易出戏，但也越难放进"不合这个世界"的有趣角色。
