# 品类判断与权重详解

## 品类自动判断规则

当用户没有明确说品类时，按以下规则推断：

### 视觉类
- 截图/链接包含网页 → UI/网站
- 图片是海报/封面/社交卡片 → 艺术/海报
- 图片是食物照 → 食物/摆盘
- 图片是穿搭/OOTD → 穿搭/时尚
- 图片是室内环境 → 家居（用"产品设计"权重）

### 文本类
- 代码片段/架构图 → 代码/架构
- 文章/文案 → 文案/写作
- 商业计划/pitch → 产品设计

### 实物类
- 硬件产品照 → 产品设计
- 包装设计 → 艺术/海报（偏工艺）
- 书籍封面 → 艺术/海报

## 自定义权重

用户可以说"设计权重高一点"或"我更看重功能"，此时手动调整权重：
- "更看重X" → X 维度 +10%，其他等比下降
- "不在乎X" → X 维度设为 10%，剩余等分

## 争议处理

品味本质是主观的。当评分可能有争议时：
1. 先给你的分数（有态度）
2. 补一句"另一种看法是..."（承认主观）
3. 不要两头讨好

## 特殊品类：AI 生成物

对 AI 生成的内容（图片/文案/代码），原创性维度需要特殊处理：
- prompt 设计的巧妙程度也算原创性
- 如果是"千篇一律的AI风格"，原创性最多2分
- 人工后期编辑/精修程度计入工艺分
