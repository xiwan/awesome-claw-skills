## Hue Shifting 色相偏移示例

以草地绿为例：

```
最暗色  #1A2E28 (深青绿，非深绿)
暗部    #2E4A3A (绿→蓝偏移，降低饱和度)
中间色  #5B8C3E (中等绿色，基准色)
亮部    #8BC34A (绿→黄偏移，提高饱和度)
最亮色  #C8E66E (黄绿色，带阳光感)
```

规律：**暗→冷(蓝/紫)+低饱和 | 亮→暖(黄)+高饱和**

## 自定义调色板 5 步法

1. **确定情绪基调**：紧张=偏红橙 / 平静=偏蓝绿 / 诡异=偏紫暗绿
2. **选 3-4 主色**：根据情绪选主色系
3. **每主色生成 4-5 梯度**：用 Hue Shifting
4. **添加 1-2 强调色**：互补色或三角色，用于UI/特效/重要物品
5. **实际场景测试**：检查色差，确认无颜色"跳出"破坏整体感
