# UI 设计规范

## 设计优先级

**清晰 > 美观 > 风格统一**

UI 首要功能是传达信息。看不清的按钮就是失败的 UI。

## 按钮设计

- **最小尺寸**：48×24 像素
- **4 态变化**：
  - 默认：基础色
  - 悬停：亮度 +10%
  - 按下：亮度 -10% + 向下位移 1px
  - 禁用：灰度 + 透明度 50%
- 文字居中，上下留白 ≥ 4px

## 面板设计

- **9-slice（九宫格）**：4角 + 4边 + 1中心，实现任意尺寸缩放
- 边框宽度：2-3px
- 内边距：8-12px

## 对话框设计

- 文字行间距：2-4px
- 文字与边框间距：8-12px
- 角色头像：32×32 或 48×48
- 打字机效果：每 30-50ms 显示一个字符

## HUD 布局

| 位置 | 内容 | 备注 |
|------|------|------|
| 左上 | 血量/状态 | 玩家视线首先到达 |
| 右上 | 小地图 | |
| 底部中央 | 技能/道具 | |
| 右上(小地图下) | 任务目标 | |

### HUD 透明度

- 非战斗：30-50% 透明（不遮挡画面）
- 战斗：80-100% 不透明（确保可读）
- 受伤时：血量条闪烁红色 + 屏幕边缘泛红
