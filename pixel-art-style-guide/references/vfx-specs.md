# 特效与粒子系统

## 像素风特效设计

### 爆炸（6-8帧）

| 帧 | 内容 | 颜色 |
|----|------|------|
| 1 | 小白点（起爆点） | 白 |
| 2 | 快速扩大的圆（膨胀） | 橙 |
| 3-4 | 最大面积（高潮） | 橙→黄核心 |
| 5-6 | 缩小（消退） | 红→深灰 |
| 7-8 | 残余烟雾消散 | 灰 |

### 烟雾（4-6帧循环）

- 使用半透明像素（alpha 通道）
- 每帧微小变化，循环播放产生缓慢飘动
- 灰色系 + 微量环境色

### 光束（2-3帧循环）

- 直线像素 + 抖动渐变
- 外层低透明度像素模拟光晕
- 核心纯白或接近纯白

### 水面（4-8帧循环）

- 水平波形运动
- 高光像素闪烁模拟反光
- 亚像素动画实现微波效果

## 粒子系统参数速查

| 参数 | 爆炸 | 烟雾 | 火花 | 落叶 | 雨雪 |
|------|------|------|------|------|------|
| 发射数量 | 20-50 | 3-8 | 10-30 | 1-3/秒 | 50-200/秒 |
| 生命周期 | 0.3-0.8s | 1-3s | 0.2-0.5s | 3-8s | 1-3s |
| 初始速度 | 高(200-500) | 低(10-50) | 极高(300-800) | 低(20-60) | 高(300-600) |
| 重力影响 | 中 | 负值(向上飘) | 高 | 低(飘动) | 高 |
| 缩放变化 | 先大后小 | 逐渐变大 | 逐渐变小 | 不变 | 不变 |
| 颜色变化 | 黄→橙→红→灰 | 浅灰→深灰 | 白→黄→橙 | 不变 | 不变 |
| 旋转 | 无 | 缓慢 | 无 | 缓慢摆动 | 无 |

## "少即是多"原则

### ✅ 用特效

- 玩家操作核心反馈（攻击命中、技能释放、受伤）
- 重要事件（Boss 登场、场景转换、剧情触发）
- 环境氛围（火把、水面、雾气）

### ❌ 不用特效

- 普通 NPC 日常动作（视觉噪音）
- 玩家每帧都在做的事（如行走灰尘，除非奔跑/着陆）
- 解谜场景（分散注意力）

## 屏幕后处理效果

| 效果 | 实现方式 | 适用场景 | 性能影响 |
|------|---------|---------|---------|
| CRT 滤镜 | 扫描线+弯曲+色差 | 复古风 | 低 |
| 色彩偏移 | RGB通道错位 | 受击/故障 | 极低 |
| 屏幕震动 | 摄像机随机偏移 | 爆炸/重击 | 极低 |
| 慢动作 | Time Scale 0.2-0.5 | 致命一击/关键剧情 | 无 |
| 径向模糊 | 中心扩散模糊 | 冲刺/加速 | 中 |
| 色彩分级 | 全局色调调整 | 场景情绪切换 | 低 |
